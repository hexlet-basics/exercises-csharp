Реализуйте метод `NormalizeUrl()`, которая выполняет нормализацию URL. Она принимает адрес сайта и возвращает его с `https://` в начале.

Функция принимает адреса в виде `АДРЕС` или `http://АДРЕС`, но всегда возвращает адрес в виде `https://АДРЕС`. На вход функции также может поступить адрес в уже нормализованном виде `https://АДРЕС`, в этом случае ничего менять не нужно.

Примеры вызова:

```csharp
Console.WriteLine(App.NormalizeUrl("https://ya.ru"));   // => "https://ya.ru"
Console.WriteLine(App.NormalizeUrl("google.com"));      // => "https://google.com"
Console.WriteLine(App.NormalizeUrl("http://ai.fi"));    // => "https://ai.fi"
```

Один из способов решить задачу:

1. Проверить, начинается ли строка с `https://`
2. Если да, вернуть строку как есть
3. Если строка начинается с `http://`, отбросить этот префикс
4. Добавить `https://` к результату

Для проверки начала строки используйте метод `StartsWith()`, а чтобы отбросить префикс — `Substring()`.
