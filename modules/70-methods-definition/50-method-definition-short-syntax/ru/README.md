В этом уроке мы изучим сокращённую запись определения метода. Разберём, как переписать в неё метод, тело которого состоит из одного `return`, и по каким признакам её узнают в коде. Мы научимся выбирать между полной и сокращённой формой определения.

Многие методы вычисляют одно выражение и сразу возвращают его результат. Так устроен метод `PickName`, который собирает полное имя из имени и фамилии.

```csharp
Console.WriteLine(North.PickName("Sansa", "Stark")); // => Sansa Stark

class North
{
    public static string PickName(string name, string surname)
    {
        return $"{name} {surname}";
    }
}
```

Вся работа этого метода умещается в выражение `$"{name} {surname}"`, но ради него в определении стоят фигурные скобки и инструкция `return`. Для таких методов в C# есть сокращённая запись через стрелку `=>`. В документации её называют expression body, то есть тело в виде выражения.

```csharp
Console.WriteLine(North.PickName("Sansa", "Stark")); // => Sansa Stark

class North
{
    public static string PickName(string name, string surname) => $"{name} {surname}";
}
```

В этом коде после списка параметров стоит стрелка `=>`, за ней выражение и точка с запятой. Фигурных скобок и `return` нет, метод вычисляет выражение и возвращает его результат сам. Тип результата по-прежнему указан в заголовке метода, и выражение должно ему соответствовать.

## Разница только в записи

Сокращённая форма меняет только то, как метод записан. Вызов, параметры и результат остаются такими же, как у полной формы. Это видно на методе сложения двух чисел, записанном двумя способами.

```csharp
Console.WriteLine(Calculator.Sum(2, 3)); // => 5
Console.WriteLine(Calculator.SumShort(2, 3)); // => 5

class Calculator
{
    public static int Sum(int a, int b)
    {
        return a + b;
    }

    public static int SumShort(int a, int b) => a + b;
}
```

В этом примере методы `Sum` и `SumShort` принимают одинаковые параметры и для аргументов `2` и `3` возвращают одно и то же число `5`. Вызывающему коду всё равно, в какой форме определён метод, поэтому полную форму можно заменить сокращённой без правок в местах вызова.

Стрелку ставят и у метода, который ничего не возвращает. После неё тогда пишут одно действие, например вызов другого метода.

```csharp
App.ShowGreeting(); // => Winter is coming

class App
{
    public static void ShowGreeting() => Console.WriteLine("Winter is coming");
}
```

В этом коде метод `ShowGreeting` объявлен как `void`, поэтому после стрелки стоит действие, а возвращать нечего. Метод выполняет вызов `Console.WriteLine()` так же, как выполнил бы его в полной форме внутри фигурных скобок.

## Когда нужна полная форма

После стрелки помещается только одно выражение. Если методу нужна переменная или несколько инструкций, его записывают в полной форме с фигурными скобками. Смешать две формы не получится. Фигурные скобки после стрелки компилятор не принимает как тело метода и останавливает сборку.

<!-- check-csharp-blocks: expect-error — фигурные скобки после стрелки в определении метода -->
<!-- lint-code-blocks: skip — намеренная синтаксическая ошибка -->
```text
class Calculator
{
    // error CS1525: Invalid expression term '{'
    public static int Sum(int a, int b) => { return a + b; };
}
```

В этом примере у `Sum` одновременно стоят стрелка и блок с `return`. Исправление зависит от того, какую форму мы выбрали. Для сокращённой формы убираем скобки вместе с `return` и оставляем `=> a + b;`, для полной убираем стрелку.

Сокращённая форма подходит методам, чей смысл виден из одного выражения. Такая запись часто встречается в коде классов, где много коротких методов вроде `PickName`. Когда выражение становится длинным и его приходится разбивать на части, полная форма с промежуточными переменными читается легче.
