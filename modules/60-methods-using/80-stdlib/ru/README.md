
C#, как и любой другой язык, поставляется с набором полезных методов. Все вместе они составляют так называемую **стандартную библиотеку**. В неё обычно входят тысячи методов, которые невозможно выучить — этого и не нужно делать. Подразумевается, что любой программист знает, где искать документацию по ним и примерно представляет себе, чего он хочет достичь. А дальше — дело техники. Если отнять у программистов интернет, то большинство не сможет ничего запрограммировать.

Для новичков эта информация часто выглядит так: «Сходи туда, не знаю куда, принеси то, не знаю что». То есть непонятно, как узнавать про эти методы, когда ты ничего не знаешь вообще. Как ни странно, не существует способа раз и навсегда познать всё, что нужно познать. Любой разработчик в процессе своего профессионального взросления знакомится со всё более интересными методами, решающими его задачи более элегантно, и таким образом пополняет свой арсенал.

Вот некоторые советы, как узнавать о новых методах:

- Всегда чётко отслеживайте, с чем вы сейчас работаете (какой тип данных). Почти всегда вы найдете необходимый метод в соответствующем разделе документации — например, для работы со строками нужно изучать строковые методы.
- Периодически открывайте раздел со стандартными методами по изучаемой тематике и просто пробегайтесь по ним, изучая сигнатуры и способы использования.
- Чаще читайте чужой код, особенно код библиотек, которые вы используете. Он весь доступен на GitHub.

## Как найти метод

Предположим, нужно взять часть строки, начиная с заданной позиции. Методы строк описаны в [документации класса `String`](https://learn.microsoft.com/ru-ru/dotnet/api/system.string?view=net-10.0). Раздел «Методы» содержит список с краткими описаниями. В нём `Substring` описан как метод, который извлекает подстроку из строки. По ссылке открывается страница метода с подробным описанием.

## Как читать документацию метода

Страница [`Substring`](https://learn.microsoft.com/ru-ru/dotnet/api/system.string.substring?view=net-10.0) начинается с таблицы «Перегрузки». В ней две строки, `Substring(Int32)` и `Substring(Int32, Int32)`. Это значит, что метод можно вызвать с одним аргументом или с двумя. Ниже каждый вариант описан отдельно.

Разберём второй вариант. Его описание выглядит так, часть текста пропущена.

```text
Substring(Int32, Int32)

Извлекает подстроку из этого экземпляра. Подстрока начинается с указанной
позиции символа и имеет указанную длину.

public string Substring(int startIndex, int length);

Параметры
startIndex
Int32
    Отсчитываемое от нуля начальное положение подстроки в этом экземпляре.
length
Int32
    Количество символов в подстроке.

Возвращаемое значение
String
    Строка, эквивалентная подстроке длины length, начинающейся startIndex
    в этом экземпляре, ...

Исключения
ArgumentOutOfRangeException
    startIndex плюс length указывает позицию, не расположенную в этом экземпляре.
    ...
```

Описание читают сверху вниз по шагам.

1. Заголовок называет вариант метода по типам его параметров.
2. Первое предложение кратко говорит, что делает метод.
3. Сигнатура показывает тип результата, имя и параметры.
4. Раздел «Параметры» объясняет каждый параметр по имени из сигнатуры и указывает его тип.
5. Раздел «Возвращаемое значение» описывает результат.
6. Раздел «Исключения» перечисляет случаи, в которых вызов завершится ошибкой.

В таблице сопоставлены части сигнатуры и аргументы вызова `"Bran".Substring(1, 2)`.

| Часть сигнатуры | Что она означает | В вызове `"Bran".Substring(1, 2)` |
| --- | --- | --- |
| `public` | Метод доступен из нашего кода | Вызываем метод у строки `"Bran"` |
| `string` перед именем | Тип результата, метод возвращает строку | Получаем строку `"ra"` |
| `Substring` | Имя метода | Пишем его после точки |
| `int startIndex` | Целое число, позиция начала подстроки | Передаём `1` |
| `int length` | Целое число, количество символов в подстроке | Передаём `2` |

Раздел «Параметры» говорит, что начальное положение отсчитывается от нуля. Поэтому подстрока начинается со второго символа строки `"Bran"`. Результат это новая строка, исходная строка при этом не меняется.

```cs
"Bran".Substring(1); // "ran"
"Bran".Substring(1, 2); // "ra"
```

Первый вызов соответствует варианту `Substring(Int32)` и берёт символы до конца строки. Второй берёт ровно два символа. Раздел «Исключения» описывает вызовы, которые завершатся ошибкой. Например, `"Bran".Substring(3, 2)` выйдет за пределы строки, потому что после позиции `3` остался один символ.

## Обозначения в справке

В справке встречаются записи, которых нет в коде урока. Они помогают прочитать описание и в вызов не переносятся.

| Запись в справке | Как её читать |
| --- | --- |
| Несколько строк с одним именем в таблице «Перегрузки» | Перегрузки метода. Вариант выбирается по количеству и типам аргументов в вызове |
| `Int32`, `Char`, `String` | Имена типов в .NET. В коде C# им соответствуют `int`, `char` и `string` |
| `StringSplitOptions options = StringSplitOptions.None` | После `=` указано значение по умолчанию, такой аргумент можно не передавать. Запись встречается, например, у метода `Split` |

Русская версия справки переведена автоматически, и описания в ней местами трудно читать. Сигнатуры и имена параметров в ней те же, что в оригинале. Если описание непонятно, замените `ru-ru` в адресе страницы на `en-us` и сверьте текст с английской версией. В коде используются имена из сигнатуры.

## Работа с незнакомым методом

Чтение справки начинается с задачи. Сначала по типу данных находим подходящий класс и метод в списке. Затем выбираем перегрузку, которая подходит под наши данные, в разделе «Параметры» проверяем смысл каждого аргумента, а в разделе «Возвращаемое значение» узнаём, что получится. После этого пробуем вызов на небольшом примере и сравниваем результат с описанием.
